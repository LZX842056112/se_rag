清理覆盖后端、前端、评测工具及文档。没有删除仍有运行入口的业务包。生产 Python/JavaScript 代码净减少 291 行；新增四个供多个调用方共用的小模块。测试和文档不计入该行数。

## 删除的内容

- 旧手写题库构造器 `build_import_chunks()`、`build_batch_eval_cases()`。当前评测使用真实切分器和落盘题库。
- 无调用的 `ParamRecord`、`get_query_default_state()`、`task_count()`。
- 无调用的历史主体回填方法 `HistoryRepository.update_item_names()`，以及旧式整目录删除方法 `MinioGateway.remove_images()`。保留现用的历史读写和上传后残留清理。
- 未使用的 `_HASH_LEN`、内部 `prompt` 状态字段、重复的证据清单初始化。
- 四个仅转发 `model_dump()` 的业务模型 `document()` 方法。调用方直接使用 Pydantic 序列化；固定输入的清理前文档用于对照。保留实际计算指标的 `QueryMetrics.document()`。
- 六个未使用导入，以及审批测试中两个失效导入位置的打桩。实际索引调用和业务断言保留。
- 七个没有页面或测试消费者的 `App` 导出。图片识别、去重和解析函数仍在公共脚本内部使用。

## 合并的逻辑及原因

- **截止时间**：共享运行层统一保存预算上下文、剩余时间和超时裁剪。共享客户端不再反向导入查询业务包。模式选择和查询装饰器仍归业务层管理。
- **MCP 传输**：统一连接、调用和清理。旧流程保留三次重试及五秒超时裕量；Agentic 保留剩余预算、读超时、会话超时和零重试。解析及降级状态由各自适配层处理。
- **分位数**：试用指标、完整入口评测和 Agentic 对照评测共用最近秩算法。样本过滤、覆盖率和空值含义没有合并或改变。
- **回答字段**：HTTP 与 SSE 共用答案、引用、图片及业务元数据构造。各自保留独有字段；HTTP 将空回答 ID 转为空字符串，SSE 保留显式 `null`。
- **知识治理**：来源缺口回写共用一个尽力执行的函数。发布成功及重复审批的补偿调用保留。回测下架不再重复写入相同候选状态。
- **待办归一化**：分组和人工忽略匹配共用问题及产品归一化规则。未知产品隔离、处理历史、会话及业务边界保留。

README 移除了易失效的文件数和行数，保留模块职责。旧审计报告增加历史说明，修正了支持度阈值已被审批使用的事实。历史证据未删除。
