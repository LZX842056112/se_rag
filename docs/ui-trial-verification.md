## 本轮修复

1. 图片仅在答案明确选择且实际上下文包含时展示。新增小编号过滤，修复末尾空图片标记。菜单中的“【图片】”文字不会截断后续步骤。
2. 帮助度和解决状态分别提交。同一回答采用稳定 Mongo 主键。首次并发写入发生冲突时合并字段，兼容旧记录的主键。
3. 参数快照优先记录注册表中的实际值，避免默认值覆盖回退依据。
4. 重排在总量上限内预留最低本地证据，联网补充不占用该名额。覆盖了上限为 2 的边界。
5. Agentic 动作使用明确的 JSON Schema。首次校验错误会反馈给重试。错误条数、位置层数和字符串长度均有限制。非法动作仍会停止流程。
6. 缺证且准备提前澄清时，在原预算内补查一次已审批 FAQ。价格、售后及冲突状态不执行此回退。
7. 决策输入保留 FAQ 问题、审批状态和来源版本。覆盖检查只读取当前问题和证据。补充型号及属性用途约束。
8. 二元草稿校验不再产生固定 100% 数值分数。没有数值评分时返回 `null`，页面显示“未评估”。旧测试历史保留原始评分，供复现。
9. 下架复用持久化撤回流程，不再硬删除候选审核记录。索引删除失败可重试。
10. 增加隔离启动入口、图片前缀策略及 E2E 资源检查。E2E 使用真实回答 ID，并按保留事件数量计算扫描轮数，避免旧数据导致误报。

$trialRun = 'ui_test_' + (Get-Date -Format yyyyMMdd) + '_' + ([Guid]::NewGuid().ToString('N').Substring(0, 8))
python -m app.rag_eval.ui_trial prepare --run $trialRun

```

python -m app.rag_eval.ui_trial serve-query --run ui_test_20261024_39501a18 --mode legacy
```
