# 客服答案配图修复记录

日期：2026-10-24。分支：`codex/agentic-rag-architecture`。

## 问题和原因

“烫金机有蓝牙吗”的答案仅给出功能结论，却展示多张设备配图。“烫金机温度多少合适”的答案说明温度设置值，却展示单个 OK 按钮图。

后端 `extract_text_image_url()` 原先遍历全部重排结果，抽出图片后直接附到答案。只有“无法作答”会阻止该行为。图片与问题同属一个产品，就可能被附上，但系统没有检查答案是否选用图片。前端还把图片标记、接口图片列表和正文中的图片链接取并集，使未经最终校验的流式链接和历史自动配图也能显示。

## 修复行为

- 功能有无、参数和一般事实默认用文字回答。提示词禁止把检索命中作为配图理由，也禁止用无关按钮图代替操作界面图。
- 只有答案明确选用的图片才进入校验。支持 Markdown 图片和末尾的 `【图片】` 或 `[图片]` 列表，校验后统一输出图片列表。
- 图片地址必须存在于实际 `answer_contexts`。没有送入生成模型的检索结果、历史链接和排除的父章节均不能作为配图依据。服务器只接受 HTTP/HTTPS 图片地址，保留有效查询参数，并按答案选用顺序去重。
- 无法作答、转人工和产品澄清不展示图片。每轮清空旧图片，防止会话状态残留。
- 旧查询和 Agent 查询使用同一函数。选图不新增模型请求。Agent 的隔离评测也执行同样的图片校验。
- 前端只显示答案显式选用与服务端最终图片列表的交集。流式期间不展示图片，不再将普通图片链接自动变成图片。旧历史中的自动图库也被隐藏，原始数据保留。
- 图片段必须以独立标记行开始，后续只能是链接或图片引用。正文中的“点击【图片】菜单”和后续操作步骤保持完整。
- 合法操作配图仍可展示，加载失败时仍显示可打开的链接。
