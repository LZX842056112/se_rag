## 独立复核与回归修复

复核覆盖查询控制、检索工具、知识发布和配对评测。已修复并增加回归测试：

- 驳回后的候选不能被失败重试重新发布，发布过程中驳回也不能使候选激活。
- 租约过期的旧任务不能删除新任务成功发布的向量。
- 独立写入开关可以启动后台任务。
- 模型提供的混合产品名称和子型号不能扩大服务端检索范围。
- 请求剩余时间不再产生无限增长的模型客户端缓存。
- 主体目录的多次 RPC 共用剩余时间，Mongo 操作也受请求预算约束。
- 成功的 Agent 查询不会因旧状态字段为空而误报未检索。
- 模型只读取计入预算的证据视图，不接收重复的后端正文元数据。
