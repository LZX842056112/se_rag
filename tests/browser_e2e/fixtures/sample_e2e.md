# E2E 联调样例设备 E2E-TEST-1000 维护说明

> 本文件为联调验证专用样例，仅用于验证导入链路（切分 / 主体识别 / 向量化 / 入库）。

## 1. 设备概述

E2E-TEST-1000 是一款用于联调验证的示例设备，具备基础运行与告警能力。

## 2. 日常维护要点

1. 每周检查电源线与接地是否牢固。
2. 每月清理散热口积尘，保持通风良好。
3. 每季度校准一次温度传感器，并记录校准结果。

## 3. 常见故障处理

- 无法开机：检查电源指示灯与保险丝是否正常。
- 温度异常：确认环境温度处于 5 至 40 摄氏度之间。
- 报警指示灯常亮：查看日志中的告警码并按手册处置。
