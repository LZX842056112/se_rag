# HAK 180 烫金机 使用与维护说明

> 本文件为联调验证专用样例，用于验证「主体识别 → 检索 → 作答」链路（导入后 kb_item_names 应出现主体 HAK 180 烫金机）。

## 1. 设备概述

HAK 180 烫金机是一款气动热压烫印设备，适用于纸张、皮革、塑料等基材的烫金与压痕工艺，
额定工作电压 220V，额定功率 1.8kW，工作台幅面 180mm × 260mm。

## 2. 保养维护要点

1. 每班次结束后清洁烫印版与硅胶垫，避免残留金箔影响下一批次效果。
2. 每周检查气路压力是否稳定在 0.4 至 0.6 MPa，发现漏气及时更换气管接头。
3. 每月对导轨与传动丝杆加注耐高温润滑脂，并检查同步带张紧度。
4. 每季度检查加热管与热电偶接线端子，紧固松动螺丝，防止温度失控。
5. 长期停机时应断开电源，并对烫印版涂防锈油。

## 3. 烫印温度与压力调试参数

- 常规纸张烫金：温度 105 至 120 摄氏度，压力 0.3 至 0.4 MPa，停留时间 0.8 至 1.2 秒。
- 皮革烫金：温度 120 至 140 摄氏度，压力 0.4 至 0.5 MPa，停留时间 1.0 至 1.5 秒。
- 塑料基材：温度 90 至 110 摄氏度，压力 0.2 至 0.3 MPa，停留时间 0.6 至 1.0 秒。
- 调试原则：先低压低温试烫，逐步升高温度与压力，直至烫印边缘清晰、无发白或糊版。

## 4. 省膜模式说明

HAK 180 烫金机支持省膜模式：开启后走箔步距按版面实际用金宽度自动收缩，
在保证烫印完整的前提下减少金箔浪费，适用于小面积、多拼版的连续烫印场景。
开启方式为在参数界面将「走箔模式」设置为「省膜」，并设定最小步距不小于 2mm。

## 5. 常见故障处理

- 烫印不清晰：检查温度是否偏低、压力是否不足、硅胶垫是否老化。
- 烫印发糊：降低温度或缩短停留时间，并检查金箔型号是否匹配。
- 走箔卡滞：清理走箔轮积胶，检查步进电机与驱动轮是否打滑。
- 温度报警：确认热电偶接触良好，必要时更换加热管。
